Estrcutura del arbol

Python
├───_Python     (Ejecutable de Python)
├───Lib         (Contenedor de Librerias)
│   └───Yos         (My libreria)
│       ├──Bdt        (Bases de Datos SQLite)
│       ├──Img        (Imagenes de la libreria Yos)
│       ├──Inf        (Informacion para desarrolladores)
│       └──Sql        (Sql de creacion y datos iniciales)
├───YosMnu.bat	(Iniciador)
├───YosMnu      (Aplicacion)
│   ├───Bdt        (Bases de Datos SQLite)
│   ├───Sql        (Sql de creacion y datos iniciales)
│   └───Script     (Sub Script de la Aplicacion)
├───YosCtr.bat	(Iniciador)
├───YosCtr      (Aplicacion)
│   ├───Bdt        (Bases de Datos SQLite)
│   ├───Sql        (Sql de creacion y datos iniciales)
│   └───Script     (Sub Script de la Aplicacion)
├───YosCtr_Www  (Aplicacion con Django)
│   ├───core        (Configuración central: settings.py y urls.py)
│   ├───templates   (Interfaz: Archivos HTML y diseño visual)
│   └───web         (Lógica Web: Modelos de datos y Vistas)
